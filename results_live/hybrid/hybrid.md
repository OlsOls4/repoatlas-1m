## Strict repro badge

The badge requires `status == reproduced` with interface_error evidence: TypeError, AttributeError, ImportError or NameError raised on doc-usage lines.
- **Coverage:** 54 repro cases ran, one for each Beam true_drift verdict and each addition. 39 got the badge.
- **Precision:** 36 of the 39 badged findings are true.
- **The badge is not an oracle.** werkzeug S38 and S39 were "confirmed" by a script that ran `werkzeug.proxy_fix.orig` as a dotted attribute, even though the docs call it an environ key. S41 was confirmed through a removed top-level alias that the docs mention only as history.
- **True drifts the badge lost:**
  - T1 starlette (could_not_run: RuntimeError in the test-session setup);
  - T11 marshmallow (could_not_run);
  - T5 and S15 structlog (no triage, so no repro);
  - werkzeug `input_stream` (a prose drift, assertion evidence only).
- T8 kept the badge through cattrs DD-1 (ImportError). The S25 script instead raised a ClassValidationError.

## Errors and disclosures

- **structlog triage failed.** Beam returned 8,794 chars of prose reasoning with no JSON (finish=stop), costing 407,397 tokens. The budget did not allow a ~405k retry. The hybrid row therefore keeps structlog's 6 candidates **untriaged** (4 true, 2 false), and they have no repro.
- **cattrs triage attempt 1 returned empty content** (307,312 + 2,151 tokens, wasted). Attempt 2 added a JSON-only retry note to the system prompt and succeeded (7 verdicts, 6 true_drift). Attempt 1 is kept in `triage/cattrs.attempt1.json`.
- **No HTTP 429, 402 or quota errors.** Calls ran sequentially under `.cache/repoatlas/ollama.lock`. Prompt caching was not observed (each triage call billed the full ~300–400k pack).
- **Source cues:** the symbol-flag wording ("method-call-signature: ...") differs in style from the whole-repo finding wording, so the model could partly tell where each candidate came from.
- **The strict tier was defined after the earlier repro run.** The universe of 45 is defined by what the methods found, so it favours the methods that contributed to it. The 7 new items came from the hybrid itself.
- **Labels:** checked against the source by an AI reviewer at the pack ref. The stored field is still `hand_verdict`. Triage verdicts that disagreed with an existing label were re-checked, and the original label stands (see `RECHECK` in `scripts/_hybrid_verdicts.py`).
